# 우리집 가계부 PWA v0.1.1

수동 기록을 중심으로 한 모바일 우선 가계부 웹앱 프로토타입입니다.

## 포함 기능
- 금액 중심 홈: 월 지출, 예산, 수입/지출/차액, 예정지출, 최근내역
- 빠른 입력: 금액만 필수, 카테고리 1단계, 결제수단, 선택 메모, 공동/비공개
- 사용내역: 목록형 / 달력형 전환
- 예산: 전체 월예산 + 필요한 카테고리별 예산
- 통계: 카테고리 비중, 최근 6개월 지출, 예산 사용률
- 반복지출: 매월 지정일 자동 반영
- 관리: 자동차 기본 엔진오일 + 사용자가 직접 추가하는 차량 관리항목
- 직접 관리: 필요할 때만 사용자가 직접 항목 추가
- 화면 스타일: 기본 / 컴팩트 / 클래식
- 테마: 시스템 / 라이트 / 다크 / 아이보리 / 웜 아이보리 / 미스트 / 리프 / 로즈
- 강조색 프리셋 10종 + 사용자 지정색
- PWA manifest + service worker
- JSON 백업 내보내기

## 현재 데이터 저장
현재 버전은 브라우저 localStorage에 저장되는 로컬 우선 프로토타입입니다.
`부부 공동/여러 명` 모드의 화면과 공개/비공개 구조는 구현되어 있지만, 다른 휴대폰과의 실시간 동기화 서버는 아직 연결하지 않았습니다.

## 실행
별도 빌드 과정이 없습니다. 정적 웹서버 또는 GitHub Pages에 그대로 올리면 됩니다.

로컬 테스트 예시:
```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.
